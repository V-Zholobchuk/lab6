# Система управління обліковими записами (Лабораторна робота №6)

Вебзастосунок на Python (Flask + SQLite) з реалізацією рольової моделі доступу (RBAC), політики паролів, хешування PBKDF2-HMAC-SHA256, CAPTCHA, активації акаунта через email-токен, захисту від Brute Force, двофакторної автентифікації (2FA: TOTP та Email OTP), входу через OpenID Connect та відновлення пароля.

## Запуск проєкту

1. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
2. Створіть файл `.env` на основі `.env.example` та задайте власні змінні оточення (`FLASK_SECRET_KEY`, `ADMIN_PASSWORD`).
3. Запустіть сервер:
   ```bash
   python app.py
   ```
4. Відкрийте у браузері: `http://127.0.0.1:5000`
